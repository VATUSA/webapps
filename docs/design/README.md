# Design docs

This directory contains [design documents](https://en.wikipedia.org/wiki/Software_design_description) for the various projects the VATUSA Web Team has, is, and/or will
undertake. Each of these documents lays out the basic requirements for what should be done, details into how those things work currently, conversations and reviews from
stakeholders, and more.
